# Pre-publish checklist

- [ ] Tracker row exists and is current (format, date, owner)
- [ ] Speaker approval
- [ ] Partner approval (if any partner appears/mentioned)
- [ ] Company comms approval
- [ ] Panel approvals (all panelists)
- [ ] Factual claims verified
- [ ] Archival/music/third-party rights cleared
- [ ] Sensitive on-screen data checked (demo accounts confirmed OK, not assumed)
- [ ] Export matches spec (16:9 full / 9:16 Short, current length limit verified)
- [ ] Captions ready
- [ ] Title, description, thumbnail, chapters ready
- [ ] Social plan reconciled with Growth (dates, standalone cut vs Short)
- [ ] Checked existing posts on YouTube + X @WorkOS
- [ ] After publish: URLs + dates in tracker, public visibility verified
